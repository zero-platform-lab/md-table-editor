# Markdown Table Editor

VS Code extension for editing Markdown tables in a visual grid UI.

## Features

- Markdown テーブルをグリッド UI で編集
- 新規テーブル作成
- セル編集（Tab / Enter でセル間移動）
- 行・列の追加・削除
- 行の並べ替え（行番号ドラッグ）
- 列の並べ替え（ヘッダードラッグ）
- テーブル端ドラッグで拡張・縮小
- 双方向リアルタイム同期
- Undo / Redo
- テーブルごとに個別パネル（複数テーブル同時編集）
- CodeLens でワンクリック起動

## Usage

- テーブルの上に表示される **Edit Table** をクリック
- または右クリック → **Edit Table in Grid** / **New Table**
- ショートカット: `Ctrl+Shift+T`（編集）/ `Ctrl+Shift+N`（新規）

## Install

```
code --install-extension md-table-editor-<version>.vsix
```
